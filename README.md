### [Employee Attrition ROI Optimizer](https://github.com/Saman-ghorayshi/Employee_Attrition_ROI_Optimizer)

Logistic regression + SMOTE pipeline that predicts which employees will leave, then finds the optimal intervention threshold to maximize net profit.

- K-Means clustering for employee segmentation
- SHAP explainability for feature attribution
- Threshold optimization: ~$62k net profit at 0.73 cutoff
- Random Forest benchmark included

### [undetect](https://github.com/Saman-ghorayshi/undetect)

6-stage pipeline that alters AI-generated images to reduce detector scores.

- Metadata stripping, color jitter, resize cycles
- Film grain, adversarial noise, FFT manipulation
- JPEG round-trip for artifact harmonization
- Tested against DeepAI: scores reduced 40-100%
